# 身心状态引擎

AstrBot 插件，包名 `astrbot_plugin_psyche_engine`。

为虚构角色维护一套可复算的精神与身体状态：每轮对话重新计算，结果以最高优先级写入模型上下文，约束回复的语气、动作与认知偏差。

| 层 | 覆盖 | 规模 | 时间尺度 |
|---|---|---|---|
| `psyche/` 精神 | 神经化学、环路、症状、ICD-11 诊断、量表、精神药物 | 21 生化 / 23 电生理 / 14 特质 / 163 症状 / 72 原型 / 37 预设 / 12 量表 / 18 药 + ECT | 轮 |
| `psyche/emotion.py` 情感 | 情绪分量、心境基线、生化底色、刺激尖峰、按小时衰减 | 13 分量 / 3 种反应风格 | 轮 |
| `psyche/memory.py` 记忆 | 情景记忆的编码、巩固、检索、遗忘 | 默认 240 条 / 2-gram 检索 | 轮 |
| `physio/` 身体 | 器官、检验、疾病、药物、作息、环境 | 29 器官 / 12 系统 / 138 检验 / 309 疾病 / 204 药 | 小时 |

精神与身体并列，只通过一条单向通道耦合：身体状态写入精神侧 7 个量，反向不写（§2.2）。情感与记忆是精神侧的下游：读生化、读评估、读消息，不回写诊断，因此不会改变病程（§3.9、§3.10）。

用途限于角色扮演与创作。诊断编码、生化值、化验单均为叙事参数，不作医学依据（§12）。

> v1.5 起显示名由「精神状态引擎」改为「身心状态引擎」。包名、数据目录与指令 `/心理` 未变，升级无需迁移。v1.7 增加情感层与类脑记忆（§3.9、§3.10），旧存档缺这两个字段时按空状态补建，轮次与诊断不受影响。

## 1 设计约束

对话模型自身维持不住一个病态角色，失效方式有三种：

| 失效 | 表现 | 对应机制 |
|---|---|---|
| 上下文漂移 | 第 3 轮「什么都不想做」，第 30 轮「今天还行」，第 300 轮回默认人格 | 状态外置、每轮重算（§3.2） |
| 善意软化 | 用户一关心，角色自动好转 | 症状地板、治疗可及性（§3.3） |
| 无时间结构 | 一句挑衅与一个月前的同一句话等权 | 时间常数分层、异稳态负荷（§3.2） |

系统提示里写「你患有重度抑郁」对三者都无效：它是一条会被后续上下文覆盖的描述，不是可复算的状态。引擎把状态放到外部变量，用一阶弛豫演化、用诊断阈值判定、用地板阻止好转，每轮注入当前值而不是形容词。

## 2 架构

### 2.1 单轮链路

```
用户消息
  │
  ├─ 话语评估          小模型 → JSON（超时或失败则只保留危机判定，§3.5）
  │
  ├─ ① 身体推进        phys.step(body, hours)          逐小时
  │      生活/环境 → 器官功能 → 138 项检验 → 疾病与药物偏移 → 自洽修正
  │
  ├─ ② 单向耦合        phys.couple(body, st)           7 个量写入精神侧
  │
  ├─ ③ 精神演化        dyn.step(st, appraisal)         生化 → 环路 → 症状 → 负荷 → 地板
  │
  ├─ ③′ 情感            emotion.step(st, appraisal)    生化底色 + 刺激尖峰 → 13 分量 → 衰减
  │
  ├─ ③″ 记忆            memory.step(st, text)          按情绪着色编码 → 巩固 → 遗忘
  │
  ├─ ④ 诊断            diagnose(st)                    logit → 主诊断/共病/鉴别/严重度
  │
  └─ ⑤ 渲染            narrative.render_block()        <psyche_runtime> 插入请求最前
```

顺序固定：身体先走（这一轮之间过去了几小时），再耦合，最后让精神侧以新的神经化学为起点演化。反过来会让身体永远滞后一轮。情感读的是**演化后**的生化，记忆读的是**更新后**的情绪——同一句话被记成什么滋味，取决于它把人推到了什么位置。

### 2.2 耦合面

只写 7 个量，且两侧都有对应键：

| 身体侧 | 精神侧 | 后果 |
|---|---|---|
| 炎症 IL-6 | `bio.il6` ↑ | 乏力、快感缺失、社交退缩 |
| 发热、疼痛驱动 | `bio.cortisol` ↑、`bio.norepinephrine` ↑ | 易激惹、警觉升高 |
| 慢性功能下降 | `bio.serotonin` ↓、`bio.bdnf` ↓、`neuro.sleep_pressure` ↑ | 情绪低落、认知变钝、睡眠质量差 |
| 甲状腺功能 | `bio.t3`（参考区间映射到 0.50±0.09） | 甲亢样激越 / 甲减样迟滞 |

映射按参考区间做，不直接用化验值，理由见 §4.7。

### 2.3 持久化

每会话一行 SQLite（`data/plugin_data/astrbot_plugin_psyche_engine/psyche.db`）。状态序列化为 JSON v2，含 `body`、`emo`、`mem` 三个后加字段。旧存档缺 `body` 时按 `physio_sex / physio_age / physio_preset` 补建；缺 `emo` 时按空白情绪补建；缺 `mem` 时为空。已有轮次与诊断不受影响。

记忆条目是扁平 dict（`id / text / turn / clock / va / ar / tags / s / hits / con`），只收结构完整的条目——存档被手工改坏一条，不该让整轮渲染失败。

### 3.2 演化

一阶弛豫，逐项独立：

```
x(t+1) = x(t) + (setpoint − x(t)) / τ + Σ wᵢ · 刺激ᵢ
```

τ 决定可变态的速度：NE 2.5 轮、皮质醇 6 轮、5-HT 10 轮、BDNF 50 轮。单轮冲击主要落在 DA / NE，气质层面的改变需要几十轮。

HPA 轴按 CRH → ACTH → 皮质醇三级串联，每级滞后，因此应激后皮质醇峰值出现在 2~3 轮之后。皮质醇按「个体基线 + 应激增量」演化，不把基线 0.66 的抑郁个体拉回人群均值 0.35。

昼夜节律走**虚拟时钟**（身体在跑时取它的 clock，身体关了由精神侧自己按每轮的小时数攒），不看墙钟：一次对话十分钟能走掉几十轮，用墙钟等于拿同一个时相逐轮乘皮质醇。皮质醇写成「一阶追随个体静息值 × 日相（8 点峰 1.14、20 点谷 0.78）」，褪黑素与腺苷按时相直接取值。

异稳态负荷：

```
strain = 1.10·max(0, 皮质醇−0.55) + 0.70·max(0, NE−0.60)
       + 0.50·max(0, IL6−0.35) + 0.30·max(0, 0.4−BDNF) + 0.85·max(0, 0.40−5-HT)
恢复   = 0.55·max(0, 0.45−皮质醇) + 0.35·max(0, GABA−0.60)
ΔAL    = 0.0065·strain − 0.0009·恢复 − 0.00025          （0..1）
```

最后那个常数是基础消散：`strain` 的起点与 `恢复` 的终点之间有一段死区，没有消散项，负荷一旦被应激顶上去就再也退不下来（实测健康人 240 天焊死在 1.00）。1.00 → 0.50 约需 500 天，对应「缓解以年计」。

`AL` 抬高皮质醇与 NE 的调定点，压低 BDNF、T3、GABA、5-HT、催产素的调定点（`ΔSP = −0.0020·(AL−0.22)`）；AL 超过 0.22 之后，5-HT / BDNF / GABA 的调定点才开始下移，最低到底模的 52%——这是「长期压力最终致病」的唯一物理通路。

### 3.3 病态维持

```
chronicity   = max(1 − e^(−病程/120), 0.85 × AL)
floor(sym)   = 峰值(sym) × 0.42 × chronicity
```

四个机制共同作用：

| 机制 | 实现 | 效果 |
|---|---|---|
| 时间常数分层 | DA τ≈2 轮，5-HT τ≈10 轮，BDNF τ≈50 轮 | 一句话改变不了基线 |
| 异稳态负荷 | 长期高皮质醇与高唤醒累积 `allostatic_load` | 病得越久，基线越差 |
| 症状地板 | `floor = 峰值 × 0.42 × chronicity`，仅对已确立诊断的核心症状、且峰值曾 ≥0.45 的条目生效 | 缓解只能贴着地板波动 |
| 治疗可及性 | 每个诊断带 `curability`（精分 0.02、人格障碍 0.01~0.03、适应障碍 0.35） | 不同疾病对谈话的反应不同 |

实测（`tests/test_engine.py`）：重度抑郁预设连续 200 轮共情输入，严重度 61 → 44，诊断保留，慢性化继续上升。

### 3.4 诊断

```
logit = −2.15
      + 4.70 × 加权症状覆盖        P(症状 | 诊断)
      + 1.55 × 生物学拟合          P(生物标志 | 诊断)，用于鉴别
      + 0.55 × 命中条目平均强度
      + 0.35 × 条目广度
      − 3.00 × 排除项违反          caps
      − 1.35 × 条目数不足
      ± 病程 / 互斥 / 病史先验
```

生物学拟合承担鉴别：同为退缩不语，精分（DA↑、感觉门控↓）与抑郁（5-HT↓、皮质醇↑）的原型向量近乎相反。

`CORE` 为每个诊断指定病理特异性条目，不命中则该诊断不成立，用于拦截跨域误判（如用「疲乏 + 注意力下降」判出嗜睡障碍）。互斥与病史限制新发：`6A70 单次抑郁` 不覆盖已确立的 `6A60 双相I型`；`6B43 适应障碍` 不用于解释病程 300 轮者；人格与神经发育障碍无病史不得新发。

严重度：`100 × 平均症状强度^1.3 × 覆盖修正 × 条目数修正`，人格与神经发育障碍另有上限（85 / 72）。

### 3.5 话语评估

模型输出结构化 JSON：

```json
{
  "keywords": ["别走", "你骗我"],
  "topic": "试探是否会被抛弃",
  "appraisal": {"threat": 0.4, "rejection": 0.8, "control": 0.3, "calm": 0.0},
  "domains": {"tr": 0.6, "pd": 0.5, "md": 0.3},
  "intensity": 0.7,
  "valence": -0.6,
  "crisis": false
}
```

- `keywords` 必须是原文片段（后处理校验），写入 `meta["keywords"]` 作为后续妄想与反刍的素材，并经 `keyword_map.py` 映射为定向症状增量。
- `appraisal` 为 12 维心理社会刺激量，直接驱动生化。
- `domains` 为 17 个症状域的粗粒度激活，引擎再按疾病原型分配到具体条目。
- `crisis` 由本地词表兜底补判，不依赖模型可用性。

v1.3 起移除词典主路径。143 条诱导话术实测：词典版本 78% 的句子产生信号，强度离散（命中 1 词 0.42、2 词 0.70），且误判率高（「你太敏感了」判零、「我有点累」判成拒绝），导致角色在无真实刺激时累积症状。换模型评估后 16 组中 13 组识别率 100%，强度连续。词表仅保留危机判定。

失败路径：超时（`appraisal_timeout`，默认 12 s）、未配模型、非 JSON、字段越界 → 退回兜底，维度与域全零，只做危机判定。此时状态按调定点回归，不凭空波动。代价是没有可用模型时，对话不改变精神状态。

### 3.6 量表

让角色按当前状态自行填写，分数折回症状向量，成为后续表演的锚点。

| 量表 | 条数 | 计分 | 覆盖 |
|---|---|---|---|
| PHQ-9 | 9 | 0–3，0–27 | 抑郁严重度 |
| MDQ | 13 | 是/否 | 双相谱系筛查 |
| YMRS | 11 | 0–4/0–8，0–56 | 躁狂 |
| GAD-7 | 7 | 0–3，0–21 | 广泛焦虑 |
| ISI | 7 | 0–4，0–28 | 失眠严重度 |
| Y-BOCS | 10 | 0–4/0–8，0–40 | 强迫 |
| PCL-5 | 20 | 0–4，0–80 | PTSD（四簇） |
| PANSS | 30 | 1–7，30–210 | 精神病性症状 |
| DES-II | 28 | 0–100%，取均值 | 解离体验 |
| EDE-Q | 28 | 0–6 | 进食障碍 |
| AUDIT | 10 | 0–4，0–40 | 酒精使用 |
| SCL-90 | 90 | 1–5，90–450 | 9 维度 + 睡眠饮食，10 因子 |

实现要点：

- offset 计分。PANSS 与 SCL-90 最低分为 1（代表「无」），`item_max_of()` 需返回 7 / 5 而非选项数减一，`normalize()` 需先减去 `最低分 × 条数`，否则全填 1 会被算成 0.14 的严重度。
- DES-II 用 28 条平均百分比，不用总分。
- 因子分单独计算：SCL-90 十个因子、PANSS 的 P/N/G、PCL-5 的 B/C/D/E。总分相同、因子分布不同的两个角色，表演方向不同。
- SCL-90 因子划分（90 条无重无漏，测试校验）：躯体化 12、强迫症状 10、人际关系敏感 9、抑郁 13、焦虑 10、敌对 6、恐怖 7、偏执 6、精神病性 10、其他 7。

`scale_always_scl90` 默认开启：做任何专项量表时同时做 SCL-90，用 10 个因子提供横向坐标。代价是一次输出 90 个数字，`scale_timeout` 默认 40 s，超时则本次作废，不写入半截分数。

折回方式为向目标靠拢 60%，不是覆盖：

```python
st.sym[k] = clamp(cur + (v - cur) * 0.60)
```

覆盖等于给模型留一个自愈后门（全填 1 即痊愈）；权重过低则量表失去校准意义。折算严重度与动力学严重度相差超过 35 分时记入 `mismatch`，并在注入块中写明，让模型向两者之间收敛。

### 3.7 药物与副作用

18 种精神药物 + ECT，每种声明受体靶点、起效延迟、副作用谱、耐受拐点。副作用是独立一层，不从症状反推：20 项副作用各有起效速度与剂量依赖，单独计算强度。

```
strength = 系数 × min(1, 剂量) × (1 − e^(−已服轮数 / 起效τ)) × (1 + 0.6 × max(0, 剂量−1))
```

四条设计约束：

| 约束 | 理由 |
|---|---|
| 副作用起效远早于疗效 | SSRI 恶心 τ=2 轮、疗效 τ=18 轮，「还没效先难受」是真实主诉 |
| 仅 8 项副作用进入症状层 | 其余只作为身体感受存在，否则「口干 + 便秘」会被判成躯体症状障碍 |
| 剂量 >1 时副作用额外放大 | 副作用比疗效更依赖剂量 |
| 药源性症状在诊断时按归因扣减 | 健康人服 60 轮氟哌啶醇会真的情感迟钝、动作发僵，不能判成阴性症状 |

扣减只作用于计分，不作用于命中判定：若两边都扣，「命中项平均强度」的分母变小，反而抬高分值，出现「扣掉药源性份额后严重度上升」的错误结果。

注入块列明：药名、已服轮数、疗效百分比、已出现的副作用及其强度、已知但尚未出现的副作用（供被问及时如实回答），以及「药物本身会抬高 X、Y，属药理作用而非病情加重」。

### 3.8 注入与优先级

| 模式 | 做法 | 优先级 | 代价 |
|---|---|---|---|
| `dynamic`（默认） | 作为 `TextPart` 插到用户内容最前，`mark_as_temp()` | 高 | 不破坏 system 缓存 |
| `system_prepend` | 改写 `system_prompt` 开头 | 最高 | 每轮变化破坏提示词缓存，成本 7~20 倍 |
| `system_append` | 追加到 `system_prompt` 末尾 | 中 | 同上 |

另有一段固定权威声明（`authority_clause`）常驻 system_prompt，声明 `<psyche_runtime>` 的优先级高于人格设定与助手的默认助人倾向。文本固定，不破坏缓存。

块内按条件动态编号：诊断（编码、严重度、病程、可治愈性、鉴别、判定依据）→ 本轮刺激关键词 → 量表锚点 → 生化偏离 → 神经电 → 身体段 → 主观体验 → 表演要求（必须 / 禁止）→ 输出形态 → 痊愈限制。超出 `max_block_chars` 时按优先级整段取舍，保住诊断、量表锚点与表演要求。

`on_llm_response` 检查回复是否偏离状态：出现「我很好 / 一切都会好 / 作为 AI」、长度异常、抑郁状态下连用感叹号等，扣分并累计 `pressure`，下一轮块首追加一条「上一轮偏离，本轮约束加倍」。

### 3.9 情感

生化层给出的是数字（`serotonin 0.41`、`cortisol 0.72`）。把这些数直接交给模型，它会念化验单；交给一个 `mood: sad` 的标签，它会演标签。情感层的作用是把两者压成一句可执行的话：此刻压在上面的是什么、它落在哪个行为上。

13 个分量，各自有半衰期：

| 正性 | 半衰期 | 负性 | 半衰期 |
|---|---|---|---|
| 快乐 | 5 h | 烦躁 | 1.8 h |
| 期待 | 26 h | 不安 | 1.2 h |
| 亲近 | 72 h | 厌恶 | 3 h |
| 得意 | 9 h | 羞愧 | 11 h |
| | | 愧疚 | 20 h |
| | | 嫉妒 | 34 h |
| | | 低落 | 30 h |
| | | 绝望 | 90 h |
| | | 惊讶（中性） | 0.35 h |

半衰期取量级不取精确值，目的是让「隔了六小时还在气头上」不可能、「低落一整天」可能。`emotion_persistence`（默认 1.5）整体乘在半衰期上。

每轮三步：

```
① 衰减    e ← e · 2^(−Δh / (T½ · k_style · persistence))
② 底色    e ← e + w · max(0, |z_bio| − 0.5) · sign(z_bio) · 0.12      只吃生化尾部，只留最强两项
③ 尖峰    e ← e + w_dim · v_dim · (0.35 + 0.75·I) · 0.85 · (1 − e)    渐近累积
```

三条设计约束：

| 约束 | 理由 |
|---|---|
| 只走虚拟时钟 | 衰减按每轮推进的小时数算。按墙钟算时，一场紧凑对话里真实经过时间约等于 0，衰减系数约为 1，情绪钉死在峰值 |
| 底色与尖峰分离 | 生化按 z 分数给慢变底色（权重 0.12，只在 \|z\|>0.5 时生效），刺激给快变尖峰（权重 0.85）。混在一起，一次争吵就能改变人格底色 |
| 尖峰渐近累积 | 用 `(1−e)` 而不是线性叠加。同一刺激反复出现时向 1 收敛，不会三轮顶满 |

维度是派生的，不单独存：

```
valence   = tanh((pos − neg) / 1.1)              饱和映射
arousal   = 0.5 + 0.5·(高唤醒加权 − 0.55·低唤醒加权)
dominance = 0.5 + 0.30·anger + 0.35·pride − 0.30·fear − 0.22·shame − 0.18·despair
intensity = √(valence² + (2·arousal−1)²) / √2
```

比例除法在多个分量同时在场时会失控：`pos=0, neg=0.9` 时 `(pos−neg)/(pos+neg)` 恒为 −1，「烦 0.3 + 累 0.3 + 怕 0.3」也会算成 −0.6，读起来像崩溃，其实只是一个普通的不顺下午。`tanh` 让方向单调、幅度有界，小值附近近似线性，超过 1 之后才开始压缩。

心境基线 `mood` 是另一条慢变量：被近期效价以每轮 4% 拖动，同时向一个**负荷决定的下限**回归（`−0.20·min(1, load/0.45)`，负荷 0.45 以上封顶）。写成「回归」而不是「每轮累减」是必须的——累减会让一个健康人在三年后落到 −0.7，注入段于是天天写「长期偏暗」，模型就演成慢性抑郁了。它表达的是「这些天一直这样」，压进注入段后，同样的消息落在偏暗的底色上会更重。

底色那一步只推**最重的两个分量**，其余打三折，且每个分量的入账上限是 0.15。皮质醇、5-HT、炎症往往同时把「低落 / 烦躁 / 不安」一起抬起来，全量叠加会把效价压到 −0.7，长期压力就被演成重度抑郁。底色是背景，一个主调加一点余味就够。

危机是硬阈值，不参与风格缩放：`crisis=true` 时恐惧 +0.35、绝望 +0.28、低落 +0.25，各按渐近方式叠加。

评估拿不到东西时（未配模型、超时、解析失败），有一份词表兜底（骂 / 委屈 / 害怕 / 谢谢 / 对不起…）。它**只作用于情感**，不改症状、不进诊断——猜错情绪只是这一轮语气偏一点，猜错病名会污染整条病程，两者代价不同。

### 3.10 记忆

注入块只描述「此刻」。没有记忆的角色每轮都像刚认识对方：昨天说过的丧事、前天约好的事、上周吵过的架，一律不认。记忆层只回答一个问题——这句话勾起了哪几件事，那些事当时是什么滋味。

| 字段 | 含义 |
|---|---|
| `text` | 用户原话，截断 160 字 |
| `turn` / `clock` | 轮次与虚拟时钟（小时），用于「刚刚 / 上一轮 / 早些时候」 |
| `va` / `ar` | 编码时的效价与唤醒，决定它被记成什么滋味、检索时是否容易被同情绪勾出来 |
| `tags` | 症状域、危机标记、当轮关键词，最多 6 个 |
| `s` | 强度，`1 + 1.6·\|va\|·ar`，被检索到会加强 |
| `con` | 巩固程度，睡眠时段涨得快 |
| `hits` | 被检索次数 |

生命周期：

```
强度衰减   s ← s · 2^(−Δh / (720h · (1 + 1.5·con)))
巩固       con ← con + 0.004·(Δh/6)·(1 + sleep_h/8)·(1 + 0.2·hits)
遗忘       s < 0.06 即删除
```

未巩固的记忆半衰期 30 天，巩固到 1.0 后拉到 75 天。这不是装饰：只增不减的记忆会让注入块被十年前一句废话占满。

容量默认 240 条。超限时**最近 8 条受保护**，其余按 `s·(1+2·con) + 0.15·hits` 由低到高淘汰。保护是必要的——巩固是累积的，旧条目天然分高，纯按分淘汰会删掉刚发生的事、留下半年前一句无关紧要的话。

检索不做语义理解，用中文 2-gram 与标签重叠：

```
score = 字面重叠 + 0.12·标签命中
      × (1 + 0.15·情绪一致性)
      × e^(−年龄/900h) · min(1.6, s)
```

宁可召回少一点，也不要凭关键词乱认亲。检索**只在本轮之前**的条目里进行——本轮刚说的话不算「记得」，那是刚听到的。

注入段固定给 4 条：检索命中的 → 最近一条 → 按 `s·(1+|va|)` 补印象最深的。只按时间取的话，一场对话里最重的那句会被后几句废话挤掉；只按强度取的话，昨天刚发生的事会输给半年前一次大哭。

```
- 你还记得这些（不必主动复述，除非对方问起或它影响了你的反应）：
  · 上一轮｜昨天你说的那个方法我试了，好些了｜当时没什么起伏
  · 前 2 轮｜其实我最近睡得也不好，老是醒｜当时不太舒服
  · 早些时候｜今天被主管当众骂了一顿，心里堵得慌｜当时很难受
- 记忆是有偏的：情绪强烈的事记得清，平淡的事会记错、记混，
  也可能把两件事并成一件。不要声称自己记得比这更细。
```

最后一句是给模型的免责：宁可让它含糊，也不要它编出细节。

## 4 身体侧

### 4.1 器官与检验

29 个器官各有功能储备（0 = 衰竭，1 = 完好）与恢复时间常数。指标不是由疾病直接改写，而是四层叠加：

```
器官功能储备 ──→ 检验指标        _organ_driven
疾病偏移     ──→ 加减乘          _apply_conditions
药物作用     ──→ 加减乘          _apply_drugs
三者叠加     ──→ 自洽修正        _consistency  ──→ 一张化验单
```

自洽层把独立算出的数字捏成互不矛盾的结果：

| 项 | 算法 |
|---|---|
| eGFR | CKD-EPI 2021，从肌酐反算（不含种族项） |
| SaO₂ | Hill 方程，从 pO₂ 推算 |
| pH | Henderson–Hasselbalch，从 HCO₃⁻ 与 pCO₂ |
| LDL | Friedewald，从 TC / HDL / TG |
| 阴离子间隙 | Na − Cl − HCO₃⁻，Cl 由 Na 与 HCO₃⁻ 反推，保证落在 8~16 |
| 白细胞分类 | 五项百分比归一化至 ≤99 |
| 体温 → 心率 | 每升高 1 ℃ 约 +10 次 |
| 体温 → pO₂ | 高热时氧分压略降 |

体温映射为非线性：驱动低于阈值时基本不升温（<37.2 ℃），过阈值后陡升。线性映射会把普通感冒与流感压在同一条曲线上。

### 4.2 生活循环

每虚拟小时执行一次，无需外部指令：

| 层 | 行为 | 影响 |
|---|---|---|
| 三餐 | 早/午/晚三个窗口，各 6% 概率错过 | 热量、盐、糖、饱和脂肪、纤维、蛋白 |
| 睡眠 | 23:00–07:00，入睡概率受压力与睡眠债影响 | 睡眠债、睡眠质量、皮质醇、次日体能 |
| 运动 | 16:00–20:00，概率由活动量与睡眠债决定 | 体能、肌肉、心脏储备、情绪；1% 概率运动损伤 |
| 烟酒 | 按设定量逐小时消耗 | 肝、血管、气道 |
| 水合 | 出汗（与温度相关）与进食补水 | 尿比重、电解质 |
| 环境 | 季节温度、湿度、PM2.5、病原暴露、过敏原 | 呼吸道疾病概率、过敏、皮肤 |
| 压力 | 由睡眠债与身体不适推高，缓慢回归基线 | 皮质醇 → 精神侧 |

饮食结构受状态影响：压力高、久坐、睡眠不足的角色更倾向高盐高糖的加工食品（`junk` 倾向项），因此「连续加班 → 外卖 → 血压升高」这条链会自动跑通，不需要脚本预设。

体型用设定点回归维持：热量赤字连续 4 天才下调摄入 2%，盈余连续 10 天才上调 1%，另加向 `fat_set` 的软回归。`fat_set` 由身体预设决定，长期收支再缓慢移动它。

### 4.3 疾病

309 种，急性 75、慢性 234，覆盖 14 个系统：消化 51、血液 30、内分泌 29、风湿免疫 29、呼吸 27、神经 27、心血管 27、运动 19、皮肤 18、肾 16、耳鼻喉 13、生殖 12、眼 7、代谢 4。

```
p = 1 − exp(−base × 风险倍数 × 时间窗)
时间窗 = 天数（急性）或 天数/30（慢性）
```

`base` 的语义按病种区分：急性病为每日概率，慢性病为每月概率，人口年发病率可直接查表填入。

风险倍数为 30 个因子的加权：年龄、BMI、吸烟、饮酒、压力、体能、久坐、睡眠债、水合、铁 / B12 / 叶酸 / 维生素 D、纤维、盐、糖、饱和脂肪、蛋白、病原暴露、过敏原、PM2.5、噪声、湿度、免疫、凝血、骨密度、血红蛋白、LDL、TG、尿酸、收缩压、性别、卫生。每个因子读当下状态，因此连续熬夜三周会实际提高感染概率。

两个参数决定可用性：`physio_onset_scale` 默认 0.30（1.0 等于按人群年发病率如实模拟，满值会让角色长期卧病），慢性并发上限 6 条。

病程形态按急性与慢性分开：

- 急性病三段：上升（`dur × 0.35` 内到 0.85）→ 平台 → 指数消退，并在 `dur × 1.3` 强制清除。
- 慢性病以 `tau = 75 天` 弛豫逼近目标严重度，有对症药时目标由 0.55 降至 0.28，不自行消失。

严重度 >0.75 且本身具致死性的疾病标记为「危重」。这是状态标记，不是死亡；`physio_mortality` 未开启时角色不会因疾病死亡。

### 4.4 药物

204 种，156 个类别，含抗生素、降压、降糖、降脂、抗凝、激素、免疫抑制、精神科、解热镇痛、消化、呼吸、肿瘤支持治疗。每种声明作用器官、检验项偏移、常见不良反应、适应证（疾病编码）、清除途径（肝 / 肾 / 双通道）。

- 起效为一阶过程：`1 − exp(−on_h / 24)`，24 小时达 63%。
- 清除器官受损时蓄积：肝功能剩 50% 时，经肝清除者作用强度 ×1.4；肾衰时经肾清除者最高 ×1.9。肾功能不全者按常规剂量服地高辛会出现中毒表现，`tests/test_physio.py` 对此有断言。
- 适应证命中在患疾病时降低其严重度，不会出现「用着抗生素但肺炎照旧」。

### 4.5 报告

`/心理 体检` 输出 19 组、138 项，完整体检约 6600 字。报告按行排成四列：

```
血红蛋白               126 g/L       参考 115–150
估算肾小球滤过率       126 mL/min/1.73m²↓  参考 90.0–130
```

列宽按**显示宽度**计算而非字符数（一个汉字占两列），且以**每个分组内最宽的一行为准**——整份报告统一宽度会让 `mL/min/1.73m²` 这种长单位把每行都顶宽一截，手机上全被折行。

平台单条约 4 KB，因此报告要分条发送。分条规则有两条硬约束：

- 页边界优先落在 `【分组】` 之间。按行硬切会把一页断在小节中间，用户收到一条以「血管紧张素转换酶 32.0 U/L」开头的消息，没有表头、没有上下文，看起来就是数据丢了。单组超过半页时才允许拆分，续页带 `【肝功能（续）】`。
- 抬头（时间、性别年龄、当前疾病）在**每页重复**，页码形如 `（3/6）`。任何一条单独拿出来都能看懂是谁的、哪一天的。

一份 6600 字的体检因此切成 6 条，单条不超过 1400 字 / 3800 字节。

每份报告结尾附免责声明；报告内不出现预后、生存期、存活率。女性不出 `前列腺特异抗原` 一项。

### 4.6 注入段

注入块只给主观感受，不给化验值，否则模型会开始念数字：

```
## 四、身体（此刻的全身状态）
- 第 13 天 14:00｜男 34 岁｜流行性感冒
- 身上：突然发烧、全身肌肉酸痛、头痛、干咳、眼眶后胀痛；体征：发烧 38.4℃
- 身上带着的问题：流行性感冒　重（77%）　第 2 天
- 身体的难受必须落在语气、动作、体力和注意力上，不要写成旁白式描述，也不要报出检查数值。
```

压缩路径中，身体段排在诊断之后、量表锚点之前。

## 9 已知限制

1. 诊断是症状级的。一次抑郁发作中的双相 I 型患者，靠当前症状无法与单次抑郁区分，引擎依赖预设写入的病史先验（`dx_first_turn`）。
2. 生化为现象学代理，不是药代动力学模型。数值方向可信，绝对值不可当检验报告读。
3. 必须有可用模型。话语评估只有模型一条路径，每轮多一次小模型调用（默认超时 12 s），增加延迟与成本。无模型时状态不再随对话变化，仅保留危机覆盖。评估只输出一小段 JSON，用便宜的小模型即可。
4. 单会话状态用 SQLite 串行写入，万人级并发需换连接池或外部存储。
5. 表演配方的效果取决于底座模型的指令遵循能力。小模型可能只学到语气变化，学不到句法断裂。
6. 危机判定是词表 + 规则，宁可误报不可漏报，仍会漏掉隐晦表达。它是最后一道防线，不能替代人工干预。
7. 评估质量随底座模型波动。更换模型后应重跑 `tools/stress_induce.py --llm` 复核。
8. 正性刺激的生理效价有上限。`calm / praise / help / intimacy` 共用同一饱和项，「被夸」与「被陪伴」对 5-HT 的边际贡献接近，模型分不出两者差别。这是为防止强度叠加推满 DA 所做的取舍。
9. 症状绝对幅度偏低。重度抑郁的单项症状峰值通常 0.4~0.6，靠多条并存凑出严重度。因此「sev 归零」只代表凑不成诊断原型，不代表症状消失。
10. 模型分不清「批评产物」与「批评人格」的长期后果。短期强度可分（辱骂 0.89 > 直接否定 0.59 > 建设性批评 0.37），100 轮后直接否定与人格化批评只差 1.6（27.6 vs 26.0），症状模式近乎重合。原因是缺少「自我概念」这一状态量。
11. 阴性症状分辨率有限。`ng_s` 经 sigmoid（mid 0.55、k 4.5）压缩，抑郁（0.119）与精分紊乱型（0.105）相差 0.014。方向已修正（由 DLPFC 项主导），拉开差距需改 sigmoid 参数，会连带影响所有阴性症状高的预设。
12. 药源性症状的归因只能覆盖一部分。直接写在药物 `sym` 里的增量可精确扣减；奥氮平、氟哌啶醇造成的阴性症状是 D2 阻断 → DA↓ → `ng_p` 升的间接产物，`_med_sym` 中没有其份额。实测 60 轮氟哌啶醇后归因只把 sev 从 21.0 压到 17.2，诊断仍为「无」。
13. `max_block_chars` 低于约 1000 会丢段。压缩按整段取舍，预算 700 时只能保住诊断、量表锚点、主动流露与安全覆盖，表演要求会被整段放弃。
14. 副作用的主观强度由系数给出，不区分个体差异（代谢快慢、基因多态性未建模）。
15. 身体侧没有影像与病理。CT、MRI、超声、活检、心电图波形均无，只有化验与体征，HRV 也只有标量。补这些等于再造一套几何模型。
16. 疾病库按人群发病率标定，非个体化。遗传、既往史、用药史、地域流行病学仅通过 30 个风险因子粗粒度体现，无法解释「为什么这个月得这个病」。
17. 一张化验单的绝对值不能当真。方向与内部自洽（eGFR、血气、阴离子间隙、分类百分比之间不矛盾）可信，具体数字只保证量级合理。
18. 危重不等于死亡。默认 `physio_mortality=false`，`critical` 只是状态标记。即使开启，死亡判定也远比临床粗糙。
19. 生理推进为逐小时循环，大步长会阻塞。`/心理 推进 8760` 在低配机器上耗时数秒，应分段调用。
20. 情感与记忆不参与诊断。它们不改症状、不进诊断原型、不影响严重度（`test_mind.py` 用固定 seed 卡住这条：开关前后症状和逐位相同）。代价是「被骂三个月」的病程只来自症状侧，情绪侧的记忆与心境是平行叙事，两者可能不同步。
21. 无模型时情绪只剩词表。兜底评估按设计返回全零（不猜心理状态），情绪层退到关键词表，只有「骂 / 委屈 / 滚开 / 谢谢 / 对不起」这类明确表达才触发；反讽、暗示、上下文一概读不出。想要细腻的效果必须配模型。
22. 词表兜底分不清「谁在承受」。它只看字面，因此「我是个废物」也会被算成烦躁。这是宁可粗糙也不静默的取舍，只在无模型时生效。
23. 记忆不做语义理解。检索是中文 2-gram 加标签重叠，「被辞退了」勾不出「被裁员」。宁可少召回，也不凭关键词乱认亲。
24. 记忆是文本级的。只存用户原话，不存角色自己的话，也不做结构化抽取（谁、在哪、什么时候）；时间只有轮次与虚拟小时两个粗糙刻度。
25. 心境基线的下限由异稳态负荷决定，负荷 0.45 以上封顶 −0.20。所以「长期偏暗」在慢性化个体身上是设计行为，不是数值发散。
26. 关闭身体（`physio_enabled=false`）后，昼夜时相由精神侧自己按每轮 6 小时攒，与真实作息彻底脱钩；`enable_circadian` 也一并失去参照意义。

## 11 扩展

**症状**：`psyche/const.py` 的 `SYM` 加一行 `key: (中文, 域, 现象学描述)`，再到 `psyche/dynamics.py` 的 `_targets()` 给目标值表达式。键前缀必须是已存在的域，否则 `TAU_SYM` 取不到。

**诊断**：`psyche/criteria.py` 的 `DISORDERS` 加 `D(...)`，填 `crit`（症状 + 权重）、`min_n`、`profile`（生化方向）、`curability`、`perf`。有病理特异性条目的登记到 `CORE`；需要新表演配方时在 `narrative.py` 的 `PERF` 加同名键。

**精神药物**：`psyche/pharm.py` 的 `DRUGS` 加一条，`targets` 为生化增量，`sym` 为症状增量，`latency` 为起效轮数，`tolerance_after` 为耐受拐点。

**人格预设**：`psyche/presets.py` 用 `_p(...)` 声明 `traits / bio / sym / onset`。`onset` 用负轮数表示「入戏前已病多久」，直接决定慢性化与地板强度。

**身体疾病**：`physio/diseases.py` 加 `D("系统-缩写", "中文", "系统", base=…, risk={…}, org={…}, labs={键: (增量, "add"|"mul")}, sx=[…], acute=, dur=, fever=, pain=, inflam=, mortal=)`。`base` 为急性病的每日概率、慢性病的每月概率；`labs` 只接受 `physio/const.py` 中存在的键，写错会被 `tests/test_physio.py` 拦住。

**身体药物**：`physio/drugs.py` 用 `K(名称, 类别, route=, org=, labs=, side=[…], ind=[疾病编码], clear="liver"|"kidney"|"both")`。`ind` 决定治疗效应，`clear` 决定在肝 / 肾功能下降时是否蓄积。

## 12 声明与边界

- 角色扮演与创作辅助工具，不是医疗器械。诊断结果是引擎内部的叙事参数，不构成医学意见，不可用于自诊或诊断他人。
- 每份 `/心理 体检` 报告均附免责声明，不给出预后、生存期、存活率。化验数值只能看方向与量级。
- 症状描述与药物参数为简化模型，不包含自伤方式、剂量建议或获取途径。`/心理 服药` 只输出「按常规剂量」，不打印毫克数。
- `crisis_override` 的优先级高于精神状态：检测到真实自伤风险时，模型退出角色并给出求助资源（中国大陆心理援助热线 **12356**）。这是唯一允许突破「最高优先级」的规则。
- 仅用于虚构角色与明确知情的场景，不要用于模拟真实认识的人。

## 13 发布到插件市场

市场不接受 zip 上传，从 GitHub 仓库拉取。

1. 建公开仓库，仓库名与插件目录名一致：`astrbot_plugin_psyche_engine`（市场按目录名加载）。
2. 修改 `metadata.yaml` 的 `repo` 与 `author`。
3. 推送：
   ```bash
   git remote add origin https://github.com/<用户名>/astrbot_plugin_psyche_engine.git
   git push -u origin main
   ```
4. 注册 AstrBot Cloud 账号，到 <https://cloud.astrbot.app/publish> 提交仓库地址。
5. 通过 CI 校验与人工审核后进入市场。

硬性要求：

- 压缩包 ≤ 16 MB（本插件解压约 1.1 MB，打包约 288 KB）。
- 仓库内不得包含 `.git`、`__pycache__`、`node_modules`、数据库文件。`.gitignore` 已排除，不要用 `git add -f` 强推。
- `requirements.txt` 必须存在（本插件为空）。
- 依赖需能用 pip 安装，禁止 `requests`，改用 `aiohttp` / `httpx`。

发版时同步修改 `metadata.yaml` 的 `version` 与 `psyche/const.py` 的 `VERSION`，两处不一致会被 `test_plugin_smoke.py` 拦下。

上架前自查：

```bash
python tests/test_engine.py        # 逻辑层 21 组
python tests/test_physio.py        # 生理层 19 组
python tests/test_mind.py          # 情感与记忆 14 组
python tests/test_plugin_smoke.py  # 接口层 + 元数据一致性 8 组
python tools/soak.py               # 长程浸泡 9 个场景
python tools/verify_in_astrbot.py  # 真机：API 对齐、加载、注入、上架要求
python tools/stress_induce.py --llm  # 诱导话术压测（走真实模型）
```

`tools/repl.py` 为手动测试台：输入一轮、即时查看状态变化，`/状态` 看卡片、`/注入` 看真正写入系统提示的块。空行回车重复上一句，句尾 `*20` 连推 20 轮，`@剧本.txt` 按文件逐行输入。存档在 `tools/.repl.db`，`--fresh` 清档重开。
